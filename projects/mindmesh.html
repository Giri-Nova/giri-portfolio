01 Overview

What it does

MindMesh is a personal AI knowledge assistant. Users upload their PDFs, notes, documents and code, then ask questions about their own knowledge base.

Instead of simply sending the question to an LLM, MindMesh retrieves the most relevant information from the user’s documents and uses it to generate an answer grounded in source references — so every answer can be traced back to where it came from.

02 How it works

From raw input to result

01
Documents · Notes · PDFs · Code

The user’s own sources, uploaded to a private knowledge base.

02
Document processing

Text is extracted and cleaned from each file type.

03
Chunking

Content is split into focused, retrievable passages.

04
Embeddings

Each chunk is converted into a vector that captures its meaning.

05
Vector database

Embeddings are indexed for fast similarity search.

06
Semantic search

The question is matched against the knowledge base by meaning, not keywords.

07
Relevant context

The best-matching passages are assembled as context.

08
LLM · RAG pipeline

The language model answers using only the retrieved context.

09
Answer + sources

A grounded response with references to the original documents.

03 Agent architecture

Beyond a basic RAG chatbot

MindMesh is designed with an agent-based architecture: an orchestrator routes each question to specialised agents that retrieve, reason, summarise and connect knowledge.
