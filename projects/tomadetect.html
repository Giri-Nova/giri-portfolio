Project 03 Computer Vision

TomaDetect

Tomato disease detection system.

An AI-powered image classification system that detects diseases in tomato plants from leaf images, helping farmers act early — before a disease spreads.

DomainAgriculture AI · Computer Vision
ModelEfficientNet-B0
Classes9 diseases + healthy
InterfaceStreamlit app
03 / 06Computer Vision
01 Overview

What it does

TomaDetect uses deep learning and computer vision to analyse a tomato leaf image and identify the most likely disease affecting the plant.

The core model is EfficientNet-B0 — lightweight enough for practical deployment while still delivering strong image-classification performance.

02 How it works

From raw input to result

01
Tomato leaf image

A photo of a single leaf is uploaded.

02
Image preprocessing

The image is resized, normalised and prepared for the model.

03
EfficientNet-B0 model

A compact convolutional network processes the image.

04
Feature extraction

Visual patterns — spots, discolouration, texture — are learned.

05
Disease classification

The leaf is assigned to one of ten classes.

06
Predicted disease + confidence

The result is shown with the model’s confidence.

03 Classes

Ten classes it can recognise

Trained on a labelled tomato leaf dataset, TomaDetect distinguishes nine diseases from healthy plants.

Yellow Leaf Curl VirusBacterial SpotLate BlightSeptoria Leaf SpotSpider MitesTarget SpotEarly BlightMosaic VirusLeaf MoldHealthy
04 Build

From dataset to working app

Preprocessing & augmentation

Images are normalised and augmented so the model generalises to real photos.

Training & evaluation

EfficientNet-B0 is trained and evaluated across all ten classes.

Streamlit interface

Upload a leaf photo and get a real-time prediction with confidence.

05 Purpose

Catch the disease early — before it spreads.

The goal isn’t simply to classify an image. TomaDetect helps farmers and agricultural users identify tomato plant diseases at an early stage, so they can take the right action before the disease spreads through the crop.

07 In short

TomaDetect — Tomato disease detection system

A deep-learning computer vision system using EfficientNet-B0 to classify tomato leaf images into multiple disease categories and healthy plants — with image preprocessing, augmentation, model training and evaluation, and a Streamlit interface for real-time disease prediction.
